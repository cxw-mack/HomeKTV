# HomeKTV 实施计划

## 阶段 1：仓库和领域基础

建立解决方案、项目边界、便携路径、领域实体、LRC 解析、文件名解析和两种队列算法。每项以单元测试验证。

## 阶段 2：数据与媒体基础设施

实现 SQLite 可重复迁移、演示数据、索引、单写入门、快速检查、备份/恢复、JSON 配置恢复、文件复制导入、SHA-256 和 FFprobe 检测。

## 阶段 3：手机点歌服务

实现会话、歌曲搜索、点歌、本人队列管理、收藏、管理员权限、端口冲突回退、SignalR 状态广播和 Vue 移动端。

## 阶段 4：WPF 和播放

实现深色触摸友好管理台、持续播放控制栏、搜索/队列/导入/设置/日志页面、LibVLC 播放服务、音轨/声道控制、LRC 显示和第二屏降级逻辑。

## 阶段 5：交付与审计

补齐自动测试、演示媒体生成器、构建与发布脚本、第三方声明和中文使用说明。执行 Release 构建、全部测试、发布、复制路径健康检查、盘符/绝对路径扫描和离线静态资源检查，生成 ZIP。

## 验证门

每个阶段必须先构建和测试后提交。最终门包括：Web 构建、.NET Release 构建、测试全绿、数据库与 API 健康检查、主 EXE 启动烟测、便携目录完整性检查、开发路径泄漏扫描和 ZIP 内容核验。
