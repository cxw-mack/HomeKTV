# 测试计划

自动测试覆盖：便携相对路径、越界拒绝、盘符变化模拟、FIFO、公平轮转和置顶；媒体文件名解析、拼音键和批量配对；LRC 元数据、定位、偏移及 KTV 双行交替进度；SQLite 新库初始化、迁移、快速检查、安全路径、配置损坏、备份恢复和并发门；端口冲突、LAN 健康端点、普通手机会话权限及重唱；MP3/FLAC/WAV/M4A 导入、显式歌词、音频与视频伴奏、随机幻灯片、标签、内嵌封面和 SHA-256；幻灯片顺序/随机/旧配置迁移/循环/损坏回退/暂停/继续/定位/重唱/释放；MV 与音频混排、防重复结束和场景残留。

每次交付执行：

1. `npm run build`，包括 vue-tsc 严格类型检查。
2. `dotnet build HomeKTV.sln -c Release`，记录警告和错误。
3. `dotnet test`，生成 TRX 报告。
4. 生成无版权测试 MV、MP3、FLAC、LRC 和三张抽象图片，验证 FFprobe、音频导入和图片回退。
5. 发布并从发布目录运行 `--portable-media-smoke --health-check`，真实连续播放 MV/MP3/MV/FLAC，等待每首 LibVLC `EndReached`，验证自定义三图、五张默认图与切歌释放。
6. 复制发布目录到不同临时路径再次健康检查。
7. 检查单显示器降级；具备第二显示器的机器上检查 HDMI 全屏与 Esc。
8. 占用默认端口后检查回退；断开互联网后检查桌面搜索、SQLite、Web 静态资源和播放。
9. 临时移除 FFmpeg、媒体文件和损坏 Settings.json，确认功能降级和恢复提示。

真实电视、声卡音轨标注、硬件 H.265 解码与热拔移动硬盘仍需在目标家庭设备上做人工验收；自动化测试不会故意在写入中物理拔盘。
