HomeKTV 家庭点歌系统（Windows 11 x64 便携版）
================================================

一、放到移动硬盘
建议使用 NTFS 格式的移动 SSD 或移动硬盘。完整复制 HomeKTV-Portable-win-x64 文件夹，不要只复制 HomeKTV.exe，也不要改变 Runtime、Web、Data、Media 等子目录结构。盘符从 D: 变为 F: 不影响歌曲，因为数据库只保存相对路径。

二、启动与电视
双击 Start-HomeKTV.bat 或 HomeKTV.exe。用 HDMI 连接电视，在 Windows“设置 → 系统 → 显示”选择“扩展这些显示器”。HomeKTV 每次启动都会重新检测显示器；有第二屏时优先全屏，无第二屏时自动以窗口方式显示。大屏按 Esc 可退出全屏。

三、手机扫码点歌
电脑和手机连接同一个家庭 Wi-Fi。在主控台点击“打开手机点歌二维码”，手机浏览器扫码并输入临时昵称。手机无需安装 App。若无法打开，先确认 Windows 网络配置为“专用网络”，再右键/运行 Configure-Firewall.ps1；脚本会解释规则并要求输入 YES，只放行当前 HomeKTV.exe 的专用网络 TCP 端口。

四、导入 MV 与歌词
主控台点击“导入歌曲”，选择合法拥有访问权的 MP4、MKV、AVI 或 MOV。程序默认把文件复制到 Media/MV；如果设置了其他便携相对媒体根目录，重启后的新导入会使用该目录。同目录同名 LRC 和 JPG/PNG 会一起导入。批量文件可按“歌手 - 歌名.mp4 / .lrc / .jpg”放入 Media/ImportBox 后确认导入。也可导入明确的 HTTP/HTTPS 视频直链；下载支持进度、取消和失败清理。系统不提供视频网站破解、DRM 绕过或未授权资源下载。

标准 LRC 示例：[00:12.50]第一句歌词。设置页可为当前歌曲按 100ms 提前或延后并保存。导入时可填写原唱音轨和伴奏音轨编号；不确定时留空，之后根据媒体检查中的音轨列表设置。

五、数据库与安全退出
数据位于 Data/HomeKTV.db，配置位于 Data/Settings.json，日志位于 Logs。设置页可手动备份/恢复；恢复前会自动备份当前数据库。请通过关闭主窗口安全退出，等待硬盘活动结束后再弹出移动硬盘。不要在运行时拔盘。

六、常见故障
SmartScreen：未签名的家庭自用程序可能提示保护。确认文件来自自己的构建包后，选择“更多信息 → 仍要运行”。
手机打不开：检查同一 Wi-Fi、二维码显示的 IP/端口、专用网络和防火墙；端口占用时程序会自动尝试后续端口。
没有画面：确认完整 Runtime/LibVLC/plugins 目录存在，更新显卡驱动，或尝试其他编码的测试视频。
FFmpeg 缺失：不影响基本播放，但媒体检测和手动转码不可用；重新解压完整发布包。手动转码默认另存 H.264/AAC MP4，只有取消“保留原文件”时才会在转码成功后删除原文件。
媒体缺失：在“导入 / 媒体”执行检查，重新导入对应 MV。播放错误会记录日志并自动跳到下一首。
配置损坏：程序保留 Settings.corrupt-日期.json 并恢复默认设置。
数据库异常：启动时如果找到有效备份，可按提示恢复最新备份；损坏数据库会保留到 Data/Corrupt。手动恢复完成后程序会关闭，请重新打开。
