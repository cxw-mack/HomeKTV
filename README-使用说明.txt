HomeKTV 家庭点歌系统（Windows 11 x64 便携版）
================================================

一、放到移动硬盘
建议使用 NTFS 格式的移动 SSD 或移动硬盘。完整复制 HomeKTV-Portable-win-x64 文件夹，不要只复制 HomeKTV.exe，也不要改变 Runtime、Web、Data、Media 等子目录结构。盘符从 D: 变为 F: 不影响歌曲，因为数据库只保存相对路径。

二、启动与电视
双击 Start-HomeKTV.bat 或 HomeKTV.exe。用 HDMI 连接电视，在 Windows“设置 → 系统 → 显示”选择“扩展这些显示器”。HomeKTV 每次启动都会重新检测显示器；有第二屏时优先全屏，无第二屏时自动以窗口方式显示。大屏按 Esc 可退出全屏。

三、手机扫码点歌
电脑和手机连接同一个家庭 Wi-Fi。在主控台点击“打开手机点歌二维码”，安卓或 iPhone 使用系统相机扫码并输入临时昵称，手机无需安装 App、无需管理员 PIN。手机端可点歌、管理自己的队列、暂停/继续、重唱、切歌、切换原唱/伴唱、开关歌词和调节主音量。若无法打开，在二维码窗口点击“配置 Windows 手机访问”并在电脑上确认一次系统授权；也可运行 Configure-Firewall.ps1。该操作只配置电脑防火墙，扫码手机不需要任何管理员权限。

四、导入歌曲、伴奏与歌词
主控台点击“导入歌曲”，可选择 MP4/MKV/AVI/MOV/WMV/MPEG/WebM，或 MP3/FLAC/WAV/M4A/AAC/OGG/OPUS/WMA。确认歌曲信息时可分别选择独立伴奏、同步歌词和多张纯音频幻灯片图片；歌词支持 LRC/TXT，并会检查是否包含可用时间标签。伴奏同样支持上述音频和视频格式，音频会保留原格式，视频会由便携 FFmpeg 提取为无损 FLAC，并在播放时与原 MV 共用时间线。程序把文件复制到便携版 Media/MV 或 Media/Audio/歌手；数据库不保存原电脑绝对路径。同目录同名 LRC/TXT 和 JPG/JPEG/PNG/WEBP/BMP 会自动匹配，WEBP 会由便携 FFmpeg 转成可离线解码的 PNG。批量文件可按“歌手 - 歌名.扩展名”放入 Media/ImportBox 后确认。也可导入明确的 HTTP/HTTPS 媒体直链；系统不提供 DRM 绕过或未授权资源下载。

标准 LRC 示例：[00:12.50]第一句歌词。大屏采用商用 KTV 常见的双行交替布局，当前句按播放进度渐进高亮；设置页可为当前歌曲按 100ms 提前或延后并保存。导入时可填写原唱音轨和伴奏音轨编号；不确定时留空，之后根据媒体检查中的音轨列表设置。

五、伴奏切换与纯音频幻灯片
歌曲存在独立伴奏或内嵌伴奏音轨时，主控台和手机端都可在原唱与伴唱之间切换。独立伴奏会在原唱模式下静音保持同步，切回伴唱时不会从头播放；如源文件本身有少量起始偏差，可用主控台的伴奏同步按钮按 50ms 调整。

纯音频默认随机显示导入时选择的图片、封面、同目录图片、歌手目录图片或程序本地生成的五张离线背景；旧版顺序配置会自动迁移为随机模式。幻灯片编辑器支持多选/文件夹导入、顺序、删除、封面、旋转、间隔、循环、转场和适配，也可以手动关闭随机。歌曲暂停、继续、定位、重唱和结束都会同步幻灯片。

六、数据库与安全退出
数据位于 Data/HomeKTV.db，配置位于 Data/Settings.json，日志位于 Logs。设置页可手动备份/恢复；恢复前会自动备份当前数据库。请通过关闭主窗口安全退出，等待硬盘活动结束后再弹出移动硬盘。不要在运行时拔盘。

七、常见故障
SmartScreen：未签名的家庭自用程序可能提示保护。确认文件来自自己的构建包后，选择“更多信息 → 仍要运行”。
手机打不开：检查同一 Wi-Fi、二维码显示的 IP/端口、专用网络和防火墙；端口占用时程序会自动尝试后续端口。
没有画面：确认完整 Runtime/LibVLC/plugins 目录存在，更新显卡驱动，或尝试其他编码的测试视频。
FFmpeg 缺失：不影响基本播放，但媒体检测和手动转码不可用；重新解压完整发布包。手动转码默认另存 H.264/AAC MP4，只有取消“保留原文件”时才会在转码成功后删除原文件。
媒体缺失：在“导入 / 媒体”执行检查，重新导入对应 MV。播放错误会记录日志并自动跳到下一首。
配置损坏：程序保留 Settings.corrupt-日期.json 并恢复默认设置。
数据库异常：启动时如果找到有效备份，可按提示恢复最新备份；损坏数据库会保留到 Data/Corrupt。手动恢复完成后程序会关闭，请重新打开。
